# 句子级写法：同一个意思，怎么写出最合适的那一句

> 上一份 `docs/网文头部文笔拆解.md` 解决的是「一章怎么写」；这一份解决「一句怎么写」。
> 核心命题只有一句：**句子没有绝对的好坏，只有「在这一段、这个位置、这个目的下，合不合适」。**
> 所以本文不教「优美句」，教的是**选句**：同一意思先写出五到七种候选，再按语境挑一个。

---

## 一、先定标准：一句话在小说里有四个任务

判断「最合适」，先问这一句此刻在干什么。四个任务，优先级从高到低：

| 任务 | 读者要得到什么 | 句子的形态 |
|---|---|---|
| **交货** | 一个信息，且只一个 | 主谓宾清楚，短，具体 |
| **立人** | 这个人是谁、什么脾气 | 动词的选择、句子的长短、说不说完整 |
| **控速** | 该快还是该慢 | 句长、断句、段落长度 |
| **埋钩** | 想不想看下一句 | 句末三个字落在哪里 |

**最常犯的错，是用「交货」的句子去干「立人」的活**——比如让一个冷静的法医说「我心中充满了难以言喻的悲伤」。信息是给了，人设崩了。

三条反向标准，用来否掉候选句：

1. 这句话换个人说也一样 → 它没有立人功能，删或改。
2. 这句话删掉不影响理解 → 它是装饰，删。
3. 这句话要读第二遍才懂 → 拆。

---

## 二、核心：一个意思，七种写法

下面七组，每组都是**同一个意思**。注意差别不在「文采」，在**这一句把读者的注意力放在哪**。

### 例 1｜意思：她听出这段录音被剪过

| # | 写法 | 类型 | 读者的注意力 |
|---|---|---|---|
| 1 | 她听出这段录音被人剪过。 | 平叙句（主谓宾） | 结论 |
| 2 | 这条线太干净了。 | 判断句（省略主语） | 她的专业判断 |
| 3 | 磁粉脱落的地方有毛刺。这一处没有。 | 物件句（主语是物） | 证据本身 |
| 4 | 剪过。刀口在第二十一秒。 | 短句切分 | 速度与确定 |
| 5 | 她把增益推到顶，又听了一遍。 | 动作句 | 她在做什么 |
| 6 | 二十一秒的底噪，十七秒的空白，中间没有过渡。 | 数字句 | 可验证的事实 |
| 7 | 「这段带子少了一截。」 | 台词句 | 人物关系 |

**选哪句**：要读者跟着推理 → 3 或 6（把证据摆出来，别下结论）；要速度 → 4；要人物冷 → 2；要压迫感 → 7（说给另一个人听，等于把风险摊开）。

**写作时的顺序建议**：先写 1（把意思写清楚），再改成 3 或 6（把结论换成证据）。**平叙句是草稿，不是成品。**

---

### 例 2｜意思：这间屋子很久没人来过

| # | 写法 | 类型 |
|---|---|---|
| 1 | 这间屋子很久没人来过了。 | 平叙句 |
| 2 | 桌上落的灰，能写字。 | 物件句（可验证） |
| 3 | 门轴响了一声，响了很久才停。 | 动作句（反常细节） |
| 4 | 没有人。没有人，也没有脚印。 | 重复句（节奏） |
| 5 | 空气里有股味道，说不上来。 | 感官句（嗅觉优先） |
| 6 | 「你们多久没进来了？」 | 台词句 |

**选哪句**：1 是最差的（作者在替读者总结）；2 最好用（一个可验证的物理量）；3 适合恐怖（门轴的时长本身就是异常）；5 慎用——「说不上来」是偷懒，除非下一句给出半个答案（「像旧报纸，又像铁锈」）。

---

### 例 3｜意思：他很害怕，但没表现出来

| # | 写法 | 类型 |
|---|---|---|
| 1 | 他心里很害怕，但没有表现出来。 | 平叙句（最差） |
| 2 | 他把手插进兜里，握住了钥匙。 | 动作句（代偿动作） |
| 3 | 后颈的汗被风一吹，凉得像贴了块铁。 | 生理句 |
| 4 | 他说得很慢。慢到每个字都要想一想。 | 短句 + 重复 |
| 5 | 「没事。」他说。声音比平时高了半度。 | 台词 + 微偏差 |
| 6 | 他没有回头。 | 否定句（省略恐惧本身） |

**选哪句**：2 最通用（人害怕时一定会找东西抓）；3 适合冷、湿、夜的外景；5 适合对话场（用「高半度」这种可测的偏差，而不是「声音发颤」）；6 适合章末（把恐惧全部压在「没有回头」四个字里）。

**这一组的通用公式**：**害怕 → 一个代偿动作 + 一个可测偏差**。不要写「害怕」这个词。

---

### 例 4｜意思：这个人快死了

| # | 写法 | 类型 |
|---|---|---|
| 1 | 他伤得很重，快要死了。 | 平叙句 |
| 2 | 命不久矣。 | 四字判断句（他人视角） |
| 3 | 血是黑的。 | 物件句（一个细节定生死） |
| 4 | 他数自己的呼吸，数到七就断了。 | 数字句 + 动作 |
| 5 | 「别叫救护车。」 | 台词句（人物自己知道） |
| 6 | 他的手还热着。脚已经凉了。 | 对比句（两端温度） |

**选哪句**：2 是《无敌镖人》式的职业判断（一句话立住主角的眼力），但它属于**旁观者**；3、6 属于**近距离视角**（读者跟着一起看到）；4 最文学，也最慢，一章最多用一次；5 最快、最狠，适合对话已经建立起来的场景。

---

### 例 5｜意思：苏雯在撒谎

| # | 写法 | 类型 |
|---|---|---|
| 1 | 苏雯在撒谎。 | 平叙句（把谜底提前交了） |
| 2 | 她回答得太快了。 | 判断句（可疑点，不给结论） |
| 3 | 她说的日期，和卷宗上差一天。 | 事实句（可核对） |
| 4 | 「你再说一遍。」沈听澜说。 | 台词句（施压） |
| 5 | 她笑了一下，笑到一半停了。 | 动作句（破绽在身体上） |
| 6 | 她没有问「哪个苏雯」。 | 否定句（该有的反应缺席） |

**选哪句**：悬疑里最值钱的是 3 和 6——**给出可核对的事实，或让「该出现的反应」缺席**。1 是最差的一种：它替读者做了判断，读者就没有参与感了。**「她在撒谎」这四个字，全书最好一次都不要出现。**

---

### 例 6｜意思：天很冷

| # | 写法 | 类型 |
|---|---|---|
| 1 | 天很冷。 | 平叙句 |
| 2 | 呼出去的气，能看见。 | 生理句 |
| 3 | 铁门把手粘手。 | 触觉句（冷到能粘住皮肤） |
| 4 | 零下十一度。 | 数字句 |
| 5 | 他把手缩进袖子，又缩了缩。 | 动作句 |
| 6 | 冷得不像十一月。 | 对比句（把异常藏进常识里） |

**选哪句**：2、3 最稳（身体是共通的）；4 适合有仪器/职业视角（我们的录音师、法医就合适）；6 适合悬疑——它同时给了温度和不对劲。

---

### 例 7｜意思：时间过去了很久

| # | 写法 | 类型 |
|---|---|---|
| 1 | 时间过去很久了。 | 平叙句（最差） |
| 2 | 烟灰掉在裤子上，他没弹。 | 动作句（用一个疏忽计量时间） |
| 3 | 窗外的光，从桌角移到墙根。 | 空间句（用光的位置计时） |
| 4 | 三根烟。 | 名词句（极简，靠读者补） |
| 5 | 他看了一眼表。两点四十。 | 数字句 |
| 6 | 录音笔的灯，红了又绿。 | 物件句（机器在替他计时） |

**选哪句**：2 最好（时间由「人忘了做的小事」体现）；3 适合独处长场景；4 适合硬汉/极简文风；6 适合我们的主题（机器一直在录，人一直没动）。

### 七组之后，抽出这张表

| 想把注意力放在 | 用哪类句 | 句末落点 |
|---|---|---|
| 结论 | 判断句（省略主语） | 结论词 |
| 证据 | 物件句（物做主语） | 那个反常的细节 |
| 推理过程 | 数字句 | 最后一个数 |
| 人物 | 动作句 / 台词句 | 动作的宾语，或台词里的关键词 |
| 情绪 | 生理句 / 否定句 | 身体部位，或「没有」 |
| 速度 | 短句切分（≤8 字） | 动词 |
| 压力 | 台词句（说给别人听） | 对方的沉默 |

## 三、十条句子级硬规则（可机械检查）

### 1. 一句一个信息

一句话里塞两个以上新信息，读者会滑过去。拆法有三种：

- **状语前置**：`他在听完第三遍之后，把带子倒回去，又听了一遍。` → `听完第三遍，他把带子倒回去。又听了一遍。`
- **定语后置**：`我见到一个长得像你兄弟说话也有点像他的陌生男人。` → `我见到一个陌生男人，长得像你兄弟，说话也有点像他。`（余光中举过的例子，前饰句太长会「尾大不掉」）
- **动作分解**：`她一边摘耳机一边把音量关掉然后转身看向门口。` → `她摘下耳机。关掉音量。转身看门口。`

### 2. 动词优先，砍掉弱动词

余光中把 `apply pressure / give authorization / take action` 这类叫「弱动词」：一个动作被拆成「笼统动词 + 抽象名词」，力量全泄了。中文里对应的就是**进行 / 作出 / 加以 / 予以 / 给予 / 使得 / 造成 / 形成**。

| 病句 | 处方 |
|---|---|
| 对录音进行了分析 | 把录音拆成四段，一段一段听 |
| 作出了判断 | 他判断 |
| 对现场加以保护 | 拉上警戒线 |
| 使得他产生了怀疑 | 他起了疑 |
| 造成了极大的伤害 | 打断了三根肋骨 |

**检查法**：句子里出现「进行/作出/加以/予以/使得」，90% 可以删掉换成实义动词。

### 3.「的」字预算：一句最多一个

「的」是定语的尾巴。一多，句子就从「夜色来袭」松成「夜色的来袭」。

- 三个「的」必拆句；
- 「白色的鸭」→「白鸭」；「灰暗的凄冷的天空」→「灰暗而凄冷的天空」；
- 「难度很高的技巧」→「很难的技巧」；「专业性的字眼」→「专门的字眼」。

**我们书里的实测**：平均每句 0.33 个「的」，含 3 个以上「的」的句子占 0.9%——这个水平要守住。

### 4. 主语只有三种：人 / 物 / 事

- **人做主语**：动作、责任、选择。打斗、追捕、审问，一律人做主语。
- **物做主语**：压迫、失控、被注视。`磁带停在那里。` `门自己开了一条缝。` 悬疑的默认主语。
- **事做主语**：判断、归纳、判决。`他没接电话，这件事本身就说明了问题。` 一段最多一句。

**中文的常态是人做主语**；「他的收入的减少改变了他的生活方式」是英式中文，正常说法是「他收入减少，就换了种活法」。

### 5. 句首不要状语

「在……的时候」「当……时」「随着……」「由于……」开头，是翻译腔与公文腔的重灾区。

- `当他推开门的时候，看见……` → `他推开门。看见……`
- `随着雨越下越大，街上的人少了` → `雨大了。街上没人了。`
- `由于磁带受潮，音质很差` → `磁带受潮，音质很差。`（删「由于」，因果自明）

### 6. 一段最多一个连词

因为 / 所以 / 但是 / 然而 / 因此 / 尽管。中文靠语序和句号表达逻辑，不靠连接词。**连词是给读者的路标，路标太密，说明路没修好。**

- `因为他不信任她，所以他没把原件给她。` → `他没把原件给她。`
- `虽然雨停了，但是天还是阴的。` → `雨停了。天还阴着。`

### 7. 后饰优先：长修饰语放到名词后面

前饰句是「关闭句」——名词压在最后，越长越憋；后饰句是「开放句」——可以一路加下去。写法：先给名词，再补特征。

- `一个穿灰色夹克、左手插兜、鞋上全是泥的中年男人走了进来` → `一个男人走进来。灰夹克，左手插兜，鞋上全是泥。`

### 8. 句末三个字是重音

读者停下来的位置在句号前。**要强调的东西，放最后。**

- `他把带子放回盒子里，动作很轻。`（重音在「很轻」）
- `他很轻地把带子放回盒子里。`（重音在「盒子里」）
- `他把带子放回去。很轻。`（重音被单独拎出来，最重）

**否定句把否定词放句末**：`他没有回头。` 比 `他没有回过头去。` 更硬。

### 9. 句长是配速器

| 句长 | 效果 | 用在哪 |
|---|---|---|
| 3–8 字 | 加速、决断、惊恐 | 冲突、发现、章末 |
| 9–20 字 | 常态叙述 | 大多数段落 |
| 21–45 字 | 减速、铺陈、窒息 | 感官堆叠、回忆、长镜头 |
| >45 字 | 几乎总是病 | 必须拆 |

**模板**：「长—短—短」用于发现（一句铺陈，两句砸下来）；「短—短—长」用于喘口气；连续三句长度接近就改一句。

### 10. 比喻预算：一章三个，且必须生活可见

老舍的说法是比喻「能不用尽量不用」，用时必须是「迫不得已」——找不到更准的词才用。汪曾祺干脆不加主观判断，只精确白描。

**标准**：喻体必须是读者见过的东西（铁、砂纸、湿报纸、旧棉絮），不能是「命运」「深渊」「潮水」这类大词。一期一章超过三个比喻，多半是在替读者抒情。

## 四、常见病句型的「一句话处方」

| 病句 | 病理 | 处方 |
|---|---|---|
| 他的心中涌起一股难以言喻的悲伤 | 抽象名词 + 大词 | 他把碗放回桌上，力气大了些 |
| 一股寒意从脚底直冲头顶 | 套话（AI 高频） | 后颈的汗被风一吹，凉得像贴了块铁 |
| 空气仿佛凝固了 | 套话 + 比喻 | 空调出风口在响。没人去关 |
| 她的眼神变得复杂起来 | 抽象 + 「起来」 | 她看了他两秒，移开了 |
| 时间仿佛在这一刻静止 | 命定旁白 | 秒针跳了三下，没人说话 |
| 他不禁感到一阵莫名的恐惧 | 三连套话 | 他没有回头 |
| 在经过长时间的思考之后，他决定…… | 句首状语 + 「经过」 | 他想了很久。最后说：「我去。」 |
| 对这个情况进行了详细的分析 | 弱动词 + 抽象名词 | 他把三份口供摊开，一行一行对 |
| 值得一提的是，现场没有打斗痕迹 | 公文腔 | 现场没有打斗痕迹 |
| 从某种意义上说，他赢了 | 模糊限定 | 他赢了。赢的人是他 |
| 那是一张令人毛骨悚然的脸 | 「令人」+ 形容词 | 那张脸上没有眉毛 |
| 他的声音里带着一丝颤抖 | 「一丝」+ 抽象 | 他说话时，尾音往上飘了一下 |
| 我不确定他是否真的听懂了 | 「是否」书面腔 | 我不知道他听懂没有 |
| 由于天气的原因，飞机延误了 | 「由于……的原因」重复 | 天气不好，飞机延误 |
| 他们之间存在着某种微妙的联系 | 「存在着」+ 抽象 | 他们用的是同一种牌子的烟 |

## 五、把「选句」变成流程（写每一句时走一遍）

```
这一句要干什么？
├─ 交货（给一个信息）
│   ├─ 信息里有「结论」→ 别写结论，写证据（物件句 / 数字句）
│   └─ 信息里有「因果」→ 删连词，用句号断开
├─ 立人
│   ├─ 情绪 → 生理反应 + 代偿动作（不写情绪词）
│   └─ 性格 → 让他把话说完整 / 说不完整（句子的完整度就是性格）
├─ 控速
│   ├─ 要快 → 拆成 ≤8 字短句，动词收尾
│   └─ 要慢 → 一个长句做感官堆叠，紧接着一个短句刹车
└─ 埋钩
    └─ 句末放：一个没解释的名词 / 一个否定 / 一句反常的台词
```

**六道自检（改稿时逐句过，只改不合格的）**：

1. 这句里有几个新信息？≥2 就拆。
2. 主语是人、物还是事？和这一段的视角一致吗？
3. 有没有「进行/作出/加以/使得」？删。
4. 有几个「的」？≥3 拆句。
5. 句首是不是状语？挪到后面或删。
6. 句末三个字是不是我想让读者记住的？

## 六、和上一份拆解的关系

- 上一份解决「**一段/一章**怎么组织」：定场、账本、规矩、缺口。
- 这一份解决「**一句**怎么落地」：主语、动词、句长、句末。
- 两份合起来才完整：**段落负责让读者往下看，句子负责让读者相信**。

头部作品的句子为什么耐读，拆到最后无非三件事：**动词准、名词实、句末狠**。形容词和比喻是这三件事做完之后才轮得到的东西。
