# 桌面图标：双击即开始创作

> 图标设计：深靛蓝圆角方块 + 白色书本、羽毛笔与一簇浪花，底部一条青绿潮汐线。
> 双击图标 → 自动启动 MongoDB 副本集 / 后端 / 前端 → 浏览器直接打开**「新建小说」**页面。

![应用图标](../assets/app-icon-256.png)

---

## 一、30 秒搞定（推荐）

### Windows

1. 在项目根目录**双击 `创建桌面图标.bat`**（首次会自动生成图标文件）；
2. 桌面会出现名为 **AI小说生成器** 的快捷方式，图标就是我们这张图；
3. 以后**双击桌面图标**：弹出命令行窗口 → 一切就绪后浏览器自动打开「新建小说」页。

> 窗口里的文字是启动日志，**别关窗口**（关了就等于停服务）。

### macOS

在项目根目录执行一次：

```bash
python3 scripts/create_shortcuts.py
```

它会把 **AI小说生成器.app** 放到你的桌面（同时项目内保留 `桌面图标/AI小说生成器.app`）。
之后双击该 App → 终端窗口跑启动流程 → 浏览器打开「新建小说」。
首次双击若被系统拦截：**系统设置 → 隐私与安全性 → 仍要打开**。

### Linux

```bash
python3 scripts/create_shortcuts.py
```

它会安装 `.desktop` 到 `~/.local/share/applications`、图标到 `~/.local/share/icons/hicolor`，
并在桌面放一份副本。若桌面上显示为"文本文件"：右键 → **允许运行 / 信任**。

## 三、图标文件清单

| 文件 | 用途 |
| --- | --- |
| `assets/app-icon-source.png` | 原始生成图（1254×1254，含烘焙棋盘格背景） |
| `assets/app-icon.png` | 去背后的 1024×1024 透明主图 |
| `assets/app-icon-{512,256,128,64,32}.png` | 通用 PNG 尺寸（网页、文档、聊天头像） |
| `assets/app-icon.ico` | **Windows**：16/24/32/48/64/128/256 多尺寸图标 |
| `assets/app-icon.icns` | **macOS**：含 icp4…ic10 全套尺寸 |
| `assets/app-icon.iconset/` | 供 `iconutil -c icns` 使用（未入库） |
| `assets/icons/hicolor/<n>x<n>/apps/ai-novel-generator.png` | **Linux** 主题图标 |
| `frontend/src/app/favicon.ico` | 网页标签页图标（已替换为新图标） |

重新生成全部尺寸（改图后执行）：

```bash
python scripts/make_icons.py                 # 默认读 assets/app-icon-source.png
python scripts/make_icons.py --source 新图.png
```

`make_icons.py` 会自动从四角泛洪去掉纯色/棋盘格背景，并**只保留最大连通块**，
所以棋盘格碎点不会残留；输出前会做一次 3×3 扩张+收缩抹掉抗锯齿白边。

## 四、快捷方式到底执行了什么

各平台的入口最终都是这一条命令（工作目录 = 项目根）：

```bash
python scripts/quickstart.py --persist-config --open-workspace new
```

- `--persist-config`：把本地 MongoDB 连接地址写进 `user_data/config/config.yaml`，
  这样之后用 `start.bat` 桌面启动器也能直接跑；
- `--open-workspace new`：健康检查通过后直接打开 `<前端地址>/zh/writing/new`；
- 其余行为与普通启动一致：起 Docker MongoDB 副本集（首次自动 `rs.initiate`）、
  按需装依赖、按需构建前端、起 8200/3300、打开浏览器。

> 只想自检不启动：`python scripts/quickstart.py --check`
> 没有 Docker、已有副本集：加 `--no-mongo --mongo-uri "mongodb://…"`

## 五、常见问题

| 现象 | 处理 |
| --- | --- |
| 双击桌面图标后窗口一闪而过 | 打开项目目录，双击 `检查环境.bat` 看是哪一项不满足；或在该目录用命令行跑 `python scripts/quickstart.py --persist-config --open-workspace new` 看报错 |
| 桌面图标显示成白纸/通用图标 | Windows 图标缓存：把快捷方式删掉重新执行 `创建桌面图标.bat`；或重启资源管理器 |
| macOS 提示"无法打开，因为无法验证开发者" | 右键 App → **打开** → 再次确认；或系统设置 → 隐私与安全性 → 仍要打开 |
| Linux 双击没反应 | 文件权限：`chmod +x ~/Desktop/ai-novel-generator.desktop`，再右键"允许运行" |
| 浏览器打开了但停在"配置数据库" | MongoDB 没起来：`docker compose -f compose.mongodb.yaml ps` 看是否 healthy；本沙箱/无 Docker 环境请用 `--no-mongo` |
| 想换图标 | 覆盖 `assets/app-icon-source.png` → `python scripts/make_icons.py` → 重新执行 `create_shortcuts.py` |
