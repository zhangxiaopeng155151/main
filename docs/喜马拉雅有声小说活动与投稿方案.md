### 三个活动的性质差异（这是选哪个的关键）

- **喜迹征稿大赛** 是「文字稿 → 有声 IP」的征稿赛，喜马拉雅旗下原创文学品牌（奇迹文学线）主办。历年同类赛（2025 第二届悬疑征文大赛）的公开规则是：
  分「影视出版向 / 新媒体网文向」两个孵化方向；**影视出版向 5 万字起**，可交「完整章节目录 + 大纲 + 2 万字正文样稿」，进决赛再补全稿；投稿需附作者简介与过往成绩；**明确要求「如使用 AI 辅助写作工具请注明」**。
  奖励是奖金 + 签约 + 影视改编 / 纸书出版机会，**所有签约作品都会做成有声书上架**——这正是「有声小说活动」的核心入口。
- **回声计划 · 快更** 是**生产效率**激励：给已经在连载的作品发更新奖励，考核的是稳定更新的节奏与字数。它不看题材创意，看「你能不能按时交稿」。
- **女频专项激励** 是**品类**激励：限女频，考核题材、更新与数据。现金 + 流量。

**结论：主投「喜迹征稿大赛」，用「回声计划」的更新节奏做生产标准，用「女频专项」做第二落点。**
理由：喜迹是唯一「靠文本质量换有声改编」的通道；回声计划反过来要求你先有一本在更的书，正好用这次创作供货；女频专项要求女频——所以**这本书要写成女主视角的悬疑**，一本稿子同时满足三条口径。

## 二、这本书要按什么规格写

把三个活动的交集翻译成写作规格：

| 约束 | 来源 | 落到本书 |
|---|---|---|
| 5 万字以上完本（影视出版向） | 喜迹 / 历届悬疑赛 | 24 章 × 2400 字 ≈ 5.8 万字 |
| 交稿时可只交「完整目录 + 大纲 + 2 万字正文」 | 同上 | 先出 24 章全纲 + 前 8 章正文（≈2 万字） |
| 稳定快更、单章自成钩子 | 回声计划 | 每章 2200–2600 字，章末必须有钩子，禁「过渡章」 |
| 女主视角、情感线有效 | 女频专项 | 女主沈听澜第一视角限知；与顾行舟是「解除的婚约」而非恋爱推进 |
| 有声化友好 | 平台属性 | 对白占比高、少生僻字、场景声可辨识、每章一个「听得见」的记忆点 |
| 原创、未发表、AI 辅助需注明 | 历届赛事规则 | 本项目全流程留痕（见第 4 节），投稿时如实注明 |

**题材选择：悬疑 + 规则怪谈 + 职业向（声纹鉴定）。**
依据：喜马拉雅悬疑类内容长期是 30 岁以下用户收听 Top 内容；平台爆款 IP（《天字第一当》《我的老千江湖》）都是「强设定 + 强钩子」的连续剧式结构。悬疑在**听**的场景里天然占优——看不见，只能靠听，而这本书的怪物就是「声音」。

## 三、选题：为什么是《十七秒》

三个候选（见项目 `topics` 字段）：

1. **《十七秒》**（选中，总分 84.4）——声音修复师能从被抹掉的录音里还原声音；每修复一段 17 秒的异常录音，录音里出现过的人就会在七天内按录音描述的方式死去。
2. 《回声档案》——档案流 + 单元剧。热度够，但「档案」这个壳太像同类跟风作，记忆点弱。
3. 《听不见的证词》——法庭 + 悬疑。女频友好，但法庭戏在有声场景里是「大段独白」，听感最差，放弃。

《十七秒》的三处差异点：

- **怪物是声音本身**，标题即设定（17 秒是硬规则），一句话能讲清，适合口播推荐位。
- **能力有明确代价**：每修一段，永久丢失一段「与声音有关的记忆」。代价从最亲的人开始消失——这条同时是情感线和恐怖源。
- **女主有生理缺陷即金手指**：右耳高频失聪让她听不到「标记音」，因此不被登记为在场者。缺陷不是卖惨，是活下来的原因。

## 四、创作过程（全部在本地跑，可复现）

用仓库里的墨脉 InkFlow 工作流推进，16 个环节全部留痕在项目 JSON 与 `logs` 里：

| 环节 | 产出 | 位置 |
|---|---|---|
| 市场热度 | 悬疑/怪谈细分热度与避坑项 | 项目 `market` |
| 方向选题 | 3 个候选 + 评分 | 项目 `topics` |
| 查重 | 与 3 部同类作品的相似度与差异化建议 | 项目 `dedup` |
| 世界观 | 1 套「回声」体系 + 6 条硬规则 + 词条 | 项目 `world` |
| 人物关系 | 6 人 + 关系边 + 冲突矩阵 | 项目 `characters` |
| 分层大纲 | 4 卷 24 章，逐章标注冲突密度 | `manuscripts/十七秒/outline.json` |
| 节奏 | 密度曲线 + 连续低密度报警 | 项目 `pacing` |
| 伏笔 | 10 条伏笔台账 + 24 条钩子 | 项目 `foreshadow` |
| 正文 | 前 8 章 | `manuscripts/十七秒/chapters/` |
| 三审 | 逻辑审 / 读者审 / 编辑审 + 5 项闸门 | 每章 `review` |
| 去 AI 味 | 前后对比与替换记录 | 每章 `deai` |

**AI 使用说明（投稿须注明）**：本书的设定、大纲、正文由「墨脉 InkFlow」工作流 + 大模型协作完成，人工负责选题判断、规则一致性校验与逐章审稿。若平台要求，可在投稿信中写明「AI 辅助创作，作者本人完成设定设计与终稿修订」。

> 有声化说明是这份投稿里最容易加分、别人又最少写的一项。见 `manuscripts/十七秒/有声化说明书.md`。

## 六、风险与注意事项

1. **活动细则必须登录核实**：字数下限、截止时间（12.31）、是否要求独家，一律以活动详情页为准；本文的「5 万字 / 2 万字样稿」来自历年同品牌赛事，属于高可信推测而非当前页面的原文。
2. **AI 声明不能省**：历届赛事规则明确要求注明 AI 辅助，隐瞒的后果比注明严重得多。
3. **不要一稿多投**：喜迹与女频专项若都要求独家，二选一；建议先投喜迹（有声改编路径更明确），被拒后再进女频专项。
4. **快更考核的是「不断更」**：回声计划按更新节奏结算，建议完稿后再开更，避免边写边更断更。
