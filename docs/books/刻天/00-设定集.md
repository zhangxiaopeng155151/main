# 《刻天》设定集

> 碑上有名，刀下有路　|　东方玄幻　|　165 章 · 四卷 · 约 49.5 万字
> 本文是写作时的"施工图"：改情节先改这里，情节才不容易自相矛盾。

---

## 一、一句话与三十秒版

**一句话**：一个只会拓碑的末等拓工，发现天道的规则是被人刻上去的——而他有能力把作废的旧规则悄悄刻回来。

**三十秒版**：这个世界的一切规则都刻在看不见的天碑上，每三百年换刻一次，旧事被抹得干干净净。碑林七坊的抄碑人能抢下几页拓本，把上一个世界的字带过来。他们只有一条铁律：只能抄，不能刻。沈砚破了这条律，为了一个世上再没人记得的人。

---

## 二、核心设定：天碑与换刻

### 1. 天碑

- 九州之上悬着一座**无形天碑**，刻着三千六百条"**律**"：风雨、生死、修行、因果、亲缘，都写在里面。
- 律不是法律，是**世界的运行参数**。律在，事情就会那样发生；律改了，事情就换个方式发生。
- 碑不可见，但**可拓**：碑林七坊所在的位置是唯一能"拓到"碑面的地方，拓碑要夜里三更前、纸不过七张。

### 2. 换刻（全书的时间轴）

| 项 | 设定 |
| --- | --- |
| 周期 | 三百年一次，称为"**大换刻**"；偶有局部的"**小换刻**"，只改一两条律 |
| 发生什么 | 旧律作废、新律生成；山河易名、人的命途重算 |
| 代价 | 与旧律绑定过深的一切被"**重排**"——人被抹去，连同别人对他的记忆 |
| 谁执行 | 司刻司的代刻人替天子执刀；这一次，要刻的人不是天子 |
| 本书前提 | 这一回换刻**提前了一百二十日**，且被人动过手脚（第 1 章那道刻痕） |

**倒计时**：卷一第 2 章得知"一百二十日"；此后每卷都在缩短（卷二剩七十三日，卷三剩十一日，卷四剩十日→零）。写作时每次转场都要交代"还剩几天"，读者的紧迫感全靠这个钟。

### 3. 拓本与褪墨

- **拓本**：碑文的纸面复制，抄碑人唯一的凭据。
- **褪墨**：拓本会自然褪色至空白，越久越淡。**无字纸**（白纸坊）不褪墨，极贵，一张顶一间铺子。
- **铁律**：抄碑人只能抄，不能刻。私刻者称"**刻天**"，其名会被天碑吞掉——从此无人记得他曾存在。

### 4. 律的四类用法（战斗与解谜的基础）

| 类别 | 作用 | 限制 |
| --- | --- | --- |
| **铭** | 强化自身：筋骨、感官、耐力 | 只能用于自己，持续一场战斗 |
| **拓** | 复制、转移、记录：抄下别人"律的写法" | 抄来的只能散用一次，用过即废 |
| **律** | 局部干涉：借火律令水沸、借风律一步三丈 | 需要"听见"那条律，闭眼一秒 |
| **刻** | 永久改写，禁术 | 折寿 + 失去一段**等重**的记忆；被刻者可能反噬 |

> 写作铁律：**任何一次施法都要当场写出代价**。看见白发、忘名、手抖，读者才相信这个世界有账。

## 三、力量体系（六阶三层）

**铭身 → 铸文 → 通律 → 掌律 → 化碑 → 无字**（每阶分初/中/后）

| 境界 | 能做到 | 代价 / 特征 |
| --- | --- | --- |
| 铭身 | 以气血在骨上铭第一道铭文；力大、目明 | 铭错了会骨裂；普通人一辈子卡在这里 |
| 铸文 | 把铭文炼成可用的文法（铭/拓/律三类） | 文法越多，身体越像"碑面"，皮肤会起纹 |
| 通律 | 听见天碑之律，丈许内借律 | 听多了会被旧律"认领"（回音涧就在干这事） |
| 掌律 | 改写一域小律：令一场雨不下、一剑必中 | 每改一次，自己的情绪淡一分 |
| 化碑 | 身自成碑，一域之主，寿数极长 | 逐渐失去人的情绪与欲望，最终不再说话 |
| 无字 | 传说中与天道同格 | 无人证实；只有"无字碑"的记载，以及本书的结局 |

**主角的特殊性**：沈砚的**逆纹**在胎里就带着（右手掌心到腕），能把抄下来的旧律**在现世重刻一次**。逆纹不属于六阶里的任何一层，所以司刻司不认得它，只能叫它"私刻"。逆纹的代价见下节。

### 代价表（写作时按此结算，不许心软）

| 刻什么 | 代价 |
| --- | --- |
| 一条小律（回音、定风、停雨） | 数月到一年阳寿 + 一段与之等重的记忆 |
| 一条主律（生死、换刻之期） | 数年阳寿 + 一段"最舍不得"的记忆 |
| 一个名字（白十三） | 自己的"存在重量"：别人看他会有重影 |
| 自己的名字 | 不折寿，只折存在——每刻一笔，世上少一个人记得他 |

## 四、七方势力

| 势力 | 性质 | 立场 | 在故事里的作用 |
| --- | --- | --- | --- |
| **碑林七坊** | 技匠集团（拓影/正字/墨骨/量天/灰烬/白纸/无字） | 中立偏守序 | 主角出身；拓本与无字纸的唯一来源 |
| **司刻司** | 朝廷衙门，设"代刻人" | 表面秩序，暗中私刻 | 主要对抗机构；宋无极借此推进提前换刻 |
| **玄清宗** | 正道魁首 | 顺天派 | 提供合法外衣与压力；常无的懦弱与临终的真话 |
| **赤霄剑冢** | 剑修宗门 | 斩律派 | 卷三军事同盟；"斩律"是另一种反抗 |
| **无量海阁** | 商盟兼情报网 | 逐利中立 | 卷三物资与消息；什么都卖，从不说谎 |
| **白骨观** | 被正道称作魔教 | 被抹者残部 | 揭示活碑真相；白十三这条线 |
| **纸人巷** | 地下帮会 | 买卖记忆 | 卷二地下线；墨七的出身与人情债 |

**势力关系一句话**：司刻司握着刀，玄清宗替它递刀，剑冢抢刀，海阁卖刀鞘，白骨观收集被刀砍掉的人，纸人巷收尸顺带做生意，碑林负责把刀口拓下来存档。

## 五、人物

### 沈砚（主角 · 19 · 拓影坊末等拓工）

- **外在**：话少、手稳、眼睛干净；右手掌心有一道淡纹，摸着像刀痕。
- **内在**：记性好到病态——他把所有拓本都背下来，因为怕忘。真正的恐惧不是死，是**被忘记**。
- **缺陷**：不肯欠人情（欠了会连夜还上）；把"记得"当作道德制高点，因此不肯原谅任何"选择忘记"的人。
- **成长**：从"我要所有人记住她" → "我替所有人记住" → "那就让我被忘记"。
- **口头习惯**：不多说，回答常常只有两三个字；难受时会用拇指搓拓碑刀的刀背。

### 沈黎（姐姐 · 24 · 三年前被抹）

- 三年前一次小换刻中被抹去，世上无人记得她，唯沈砚的逆纹保留她的存在。
- 她左眼比右眼低一点（这一句是全书情感的锚，反复出现，第 149 章由她本人当众说出口）。
- 真身：司刻司造的**活碑**之一，坛底承重的那块，**自愿**。
- 她的选择："别救我。我要是出来，这一纪就没了。"

### 柳无咎（师父 · 57 · 拓影坊坊主 · 断三指）

- 曾替司刻司伪刻三次，第一次的代价是妻子被抹；此后一生在找"第九碑"。
- 教学方式：只讲规矩不讲道理；把最脏的活留给徒弟，让他先习惯代价。
- 死法：把从自己骨头上拓下的最后一块碑文交给沈砚，被碑反噬。
- 遗言："别学我。"（卷一第 7 章他说过"别学我刻"，卷三说"别学我"，一个字的差别就是全书主题的收紧。）

### 裴玄衣（女主 / 对手 · 22 · 司刻司最年轻的代刻人）

- 刻字如刀，右手能同时握两支笔。相信"为了让多数人活，少数人必须被删"。
- 身世：父亲是上一纪**自愿的活碑**，母亲被抹；她自己本该不存在，被司刻司当"证据"养大。
- 与主角的关系线：执法者 → 交易对象 → 同谋 → 同盟 → 唯一记得他的人（差一点）。
- 她的转折点：第 136 章查到父亲名册上的"自愿"二字——她一直以为父亲是被杀，其实是被纪念。

### 宋无极（主要反派 · 63 · 司刻司大监）

- 目的是**删掉"重排"这一条律**，代价是半数不合律者被抹。他自己算过，算得很准。
- 私德近乎完美：不贪、不近女色、给下属添粥、替人拂灰。越是温和越可怕。
- 女儿宋若死于上一次换刻的重排，他把她的名字在旧城碑上描了三十年，墨积成壳。
- 终局：他想用自己的命换女儿的命，手却早已被伪刻的律认领，刻不动；求沈砚替他刻，被拒；名字被天碑吞掉，成了没人记得的人。

### 墨七（同伴 · 17 · 纸人巷纸匠）

- 胆小、贪财、嘴碎。做的纸人能替人挡一次刀，脸按记忆做——所以做错了脸就成了"别人"。
- 妹妹的记忆被卖过三次，已经不认得他；他攒钱、卖记忆、最后把自己忘了。
- 死法：换刻之夜用最后一个纸人替沈砚挡刀，纸人的脸是他自己的。遗言："这次我记得了，我叫墨七。"

### 白十三（白骨观主 · 年龄不详）

- 是所有遗忘的**集合意志**：世人多忘一件事，她就多一分；她的脸每天都不一样。
- 诉求极小：想被人叫一声名字。
- 第 109 章自请被刻成一条律，名字由沈砚给，叫"十三"。她留下的那条律在换刻之夜救了场（第 156 章）。

### 常无（玄清宗长老 · 百岁开外）

- 六十年前就看出天碑有伪，什么都没做。卷三闯狱送真碑拓本，被杀。
- 遗言："六十年前我该动。"

## 八、主题与文风

**主题**：秩序以遗忘为代价。记录真相的人，往往必须自己被抹去。

**写作风格**：

1. **第一人称（沈砚）+ 第三人称（反派/配角）** 交替。主角线短句、重手感；反派线稳、体面、慢。
2. **不解释设定**：人物只说自己知道的，世界观靠后果显形。
3. **战斗写手感**：刀重、血温、笔锋的顿处；禁止"滔天""轰然""不可一世"。
4. **每章一个钩子**：章末留一个未解的疑问或一次代价结算，不做纯过渡章。
5. **代价当场结算**：白头发、忘名字、手抖，必须在同一章内出现。
6. **伏笔不藏太深**：第一次出现要让读者"注意到但不在意"，回收时要让读者"想起来但没猜到"。

## 九、设定一致性条款（写之前先读这一段）

1. **律不能凭空产生**：所有超自然现象必须能对应到某条律；没有对应律的，就是**伪刻**（这是全书解谜的钥匙）。
2. **刻必须付账**：任何人刻律都要付出记忆与寿数，反派也不例外——宋无极付的是女儿、妻子、三十年的手。
3. **活碑必须自愿**：不自愿的刻不上字。这条规矩保证了"沈黎不能救"的逻辑成立，也是宋无极毕生的难题。
4. **拓本会褪**：证据是有保质期的，所以"记忆"必须有实物或人承载，不能凭空存在。
5. **被抹 ≠ 死亡**：被抹者成为活碑，还醒着，还能听见。这一点在卷二揭示，卷四兑现。
6. **名字即存在**：谁的名字被抹，谁就从"册"里消失；刻天罪名的判词里连"沈砚"两个字都不写——这是全书最冷的一笔。
7. **不写全能主角**：沈砚全书只刻了不到十次，每次都留下永久的缺口；他的强项始终是"记得"和"拓"。
