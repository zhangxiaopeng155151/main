## 四、现在的机械闸门（`PROSE_RULES`）

| 规则 | 例句（会被拦下） | 处理 |
|---|---|---|
| 重复虚词 | 的的 / 是是 / 就就（「了了」除外，「开不了了」不算） | 删一个 |
| 口误式用词 | 奇数的是 / 奇怪地是 / 似乎好像 | 改成正常说法 |
| 介词结构淹没主语 | 通过把带子重放，使在场者被登记 | 换成「因为…所以…」 |
| 原因重复 | 原因是因为他没有签字 | 「原因是」后不接「因为」 |
| 约数重复 | 大约三分钟左右 | 二选一 |
| 被…所…混用 | 被听到的人所登记 | 只留一种被动 |
| 动词滥用「进行」 | 对母带进行了一次比对 | 直接用「比对」 |
| 存现句多加「了」 | 就会多了一个人 | 多出一个人 |
| 分钟与秒对不上 | 三十五分钟，四千七百多秒 | 一分钟 60 秒 |

## 六、还没改、但要注意的地方（留给下一轮）

1. **「听不见名字」有两条规则**：第 6 章是「失去与名字有关的声音记忆」，第 12 章是「念名字的人从此听不见被念的人的名字」。两套机制并存，容易读混。目前靠上下文区分，若做有声剧，建议在第 12 章加一句人物解释。
2. **苏雯的年龄改了（44→56）**，第 3 章之后所有「她比你早一步」的气场要靠动作维持，不能再靠「年长」暗示。
3. **父亲线**在第 21 章才抛出（「他在门里等了二十六年」），第 22–24 章必须给一个落点，否则是悬空的钩子。
