# 改写规则
1. 删掉可删的副词与套话：仿佛 / 似乎 / 不禁 / 顿时 / 缓缓 / 微微 / 一丝 / 莫名 / 深深地。
2. 打破均匀句式：让长短句交替，允许出现 3-6 字的短句。连续三句结构相同就改掉一句。
3. 把抽象情绪换成可见的动作或身体反应（不写「他感到很愤怒」，写「他把碗放回桌上，力气大了些」）。常见替换：
   - 「她非常紧张」→ 具体的身体失控：手指在桌沿敲了三下才发现自己停了；
   - 「他心里一沉」→ 一个计价动作：他把报价在心里减了一半，还是不够；
   - 「气氛很压抑」→ 一个可测的物理量：空调出风口在响，没人去关；
   - 「他说不出话」→ 一次失败的开口：他张了张嘴，先咳了一声；
   - 「时间过去很久」→ 一个具体的刻度：烟灰掉在裤子上，他没弹；
   - 「他感到害怕」→ 一个生理反应：后颈的汗被风一吹，凉得像贴了块铁。
4. 删掉段末总结句、命定感旁白（「从这一刻起…」「而他不知道的是…」）。
5. 对话要有人味：允许打断、答非所问、废话、方言词。取消礼貌的完整句。
6. 减少破折号与排比；比喻只用一次，且必须是生活里能见到的东西。
7. 保留所有情节信息、伏笔与章末钩子，不得改动事件顺序。
8. 字数不得低于 {{MIN_WORDS}}，目标 {{TARGET_WORDS}}。
9. 句子层（见 docs/句子级写法.md）：一句塞两个以上新信息的拆开；删「进行/作出/加以/予以/使得」换成实义动词；一句里三个「的」就拆句；删句首「在……的时候 / 当……时 / 随着…… / 由于……」；删多余的连词（因为/所以/但是/然而），用句号断开；把想强调的词放到句末三个字的位置。
10. 文笔层（见 docs/网文头部文笔拆解.md）：删掉段末总结句；把整段只有视觉的描写补一个气味或触感；把「因为/也就是说/这说明」的解释句改成一句台词；每 300–500 字保证收在一次小动作或一句反常的话上；全章至少留 1–2 句 15 字以内、具体到能被记住的句子（不要抒情，不要金句腔）。
