# 硬性要求
1. 5 个选题之间必须分属不同的「情绪引擎」（例如：复仇爽感 / 解谜快感 / 归属治愈 / 恐惧战栗 / 身份颠覆），不能是同一本书的变体。
2. novelty 低于 60 的方案要明确写出它靠什么赢。
3. 避免直接使用已知作品的主角名、组织名、专有名词。
4. total 必须等于公式计算结果（保留一位小数）。
